# Rocketseat Experts Club — Análise de dados COVID-19

Exercícios de análise de dados com pandas, feitos no curso do Rocketseat Experts Club.

## Datasets não incluídos

Os notebooks `analise-dataset.py`, `Untitled1.ipynb` e `dataset_covid_19_semanal.ipynb`
referenciam os arquivos `caso_full.csv` (~110MB) e `covid_dataset_v2.csv` (~53MB).

Esses arquivos **não foram incluídos neste repositório** por serem grandes demais para
o Git. São datasets públicos de casos de COVID-19 no Brasil, originalmente
disponibilizados pelo projeto [Brasil.IO](https://brasil.io/dataset/covid19/caso_full/).

Para reproduzir os notebooks, baixe os dados públicos equivalentes e ajuste o caminho
dos arquivos no código.
