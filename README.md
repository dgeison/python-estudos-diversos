# Python — Estudos Diversos

Coleção de exercícios e experimentos pontuais, sem escopo suficiente para
repositórios próprios.

## Estrutura

- `fast_api_moderna/` — exemplo básico de FastAPI.
- `design_patterns_python/` — exercícios de design patterns (Singleton) em
  Python, com testes de thread-safety.
- `claude_okr_alura/` — OKRs de um exercício de marketplace (curso Alura),
  com anotações e planilha.
- `curso_alura_2026/` — notebook do curso "Python e Inteligência Artificial"
  (Alura), usando a API do Gemini via variável de ambiente
  (`GEMINI_API_KEY`, não incluída neste repositório).
- `go/` — exercício básico de Go.
- `rust/` — exercício básico de Rust.
- `projeto_aulas_python/` — anotações completas de um curso de Python e uma
  página HTML de apoio.

## Rodando o notebook do curso Alura

O notebook em `curso_alura_2026/` espera uma variável de ambiente
`GEMINI_API_KEY` (crie um `.env` local com `python-dotenv`, não incluído
aqui por conter credenciais).
